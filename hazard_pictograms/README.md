# Chemical Hazard Pictograms - Switzerland

This collection contains the nine GHS pictograms used in Switzerland.

| Code | Meaning |
|---|---|
| GHS01 | Explosive |
| GHS02 | Flammable |
| GHS03 | Oxidizing |
| GHS04 | Gas under pressure |
| GHS05 | Corrosive |
| GHS06 | Toxic |
| GHS07 | Harmful or irritant |
| GHS08 | Serious health hazard |
| GHS09 | Hazardous to the aquatic environment |

Each pictogram is provided as a PNG and a vector EPS file.

**Official Swiss source:** [Cheminfo - Labelling and hazard symbols](https://www.cheminfo.ch/fr/etiquetage)
